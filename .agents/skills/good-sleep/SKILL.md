# Good Sleep

Read .agents/docs/JOURNAL.md, LTM/INDEX.md, and TODO.md. Identify durable facts and unresolved work separately; the backlog belongs in TODO, not hidden inside settled memory.

Group facts by topic, not date. Reuse existing topic notes before adding a new one. Explain substantial topic regrouping in a progress update, then proceed within the requested consolidation scope.

For each topic, preserve decisions, exact source paths, contracts, reproduction conditions, test evidence, and pitfalls. Synthesize overlapping entries rather than copying a timeline. Verify current claims against code; mark superseded facts rather than treating journal age as truth.

Update the source-topic table in LTM/INDEX.md; preserve its separate synthesis table. Add deduplicated unresolved tasks to TODO with source and completion criteria.

Append a journal consolidation record mapping source entry headings to topic files. Do not remove or rewrite existing journal entries. Compaction is the separate reconcile-journal-ltm workflow.

Run make harness-check and inspect referenced files. If there is no new durable material, report that without manufacturing notes. Consolidation does not authorize implementation of discovered TODOs.
