# Deep Sleep

Read .agents/docs/LTM/INDEX.md and only the topic notes relevant to candidate overlaps. Group by architecture or a shared failure mechanism, not by date or target file count. A small cohesive topic set may need no consolidation.

Explain the proposed synthesis/source mapping. Create or update concise synthesis documents under LTM with links to their included sources, stable facts, operational guidance, evidence, and pitfalls. Preserve source topic documents.

Keep contradictions visible and check current code before resolving them. Do not silently discard an inconvenient source. Refresh the synthesis table in INDEX.md while retaining the source-topic table.

Flag facts that belong in canonical overview/architecture/testing/gate docs for distill-memories; do not expand this workflow into rewriting those documents.

Append a journal record listing syntheses, sources, standalone topics, and promotion candidates. Run make harness-check. Do not delete sources or compact the journal as part of synthesis.
